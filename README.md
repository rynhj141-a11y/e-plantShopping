🌿 Plant Shopping (React + Redux)

Online plant store built with React and Redux Toolkit. Users browse plants by category, add them to a cart, change quantities and see the total update in real time.

✨ Features
Landing page and product listing grouped by category
Add to cart, with the button disabled once the plant is added
Cart icon showing the live number of items
Cart page: increase / decrease quantity, remove an item, see subtotal per item and the total
Global state managed with Redux Toolkit
🛠️ Tech stack

React · Redux Toolkit · JavaScript · CSS · Vite [or Create React App, check your project]
